TL;DR On June 17, 2026, security researchers identified a software supply cha in attack involving the npm package easy-day-js , a malicious package designed to impersonate the popular JavaScript date library dayjs. Sonatype is tracking this campaign as sonatype-2026-003926 . Attackers compromised part of the Mastra AI framework and added easy-day-js as a dependency across a large number of Mastra packages.
